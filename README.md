## Panel version notes / توضیحات نسخه‌های پنل

### v1.0.0 — Proxy-enabled gateway / گیت‌وی پروکسی‌دار

**English**

This fork version changes the original `v0.0.0` gateway behavior. Gateways generated by v1 use public CONNECT proxies from the maintained public proxy list instead of connecting directly to the requested destination. The gateway remembers its preferred proxy and reuses it while it remains healthy. It marks a proxy unhealthy and switches when it fails, its TCP RTT exceeds 800 ms, or upload/download rate stays below 200 KiB/s for repeated samples.

**فارسی**

این نسخهٔ فورک، رفتار گیت‌وی نسخهٔ اصلی `v0.0.0` را تغییر می‌دهد. گیت‌وی‌هایی که v1 می‌سازد به‌جای اتصال مستقیم به مقصد، از پروکسی‌های عمومی CONNECT در فهرست عمومی استفاده می‌کنند. گیت‌وی پروکسی ترجیحی را نگه می‌دارد و تا وقتی سالم باشد از همان استفاده می‌کند؛ در صورت قطع‌شدن، پینگ TCP بیشتر از ۸۰۰ میلی‌ثانیه، یا پایین‌ماندن سرعت آپلود یا دانلود از ۲۰۰ کیبی‌بایت‌برثانیه در چند نمونه، آن پروکسی را ناسالم تشخیص می‌دهد و سراغ گزینهٔ دیگری می‌رود.

### v2.0.0 — Selectable Direct and Non-Direct gateways / انتخاب گیت‌وی مستقیم یا پروکسی‌دار

**English**

When creating a gateway, v2 lets the panel user choose:

- **Direct:** deploys the original `v0.0.0/worker.js` gateway behavior and connects to the destination without a public proxy.
- **Non-Direct:** keeps the v1 public-proxy gateway, including its preferred-proxy caching and unhealthy-proxy replacement behavior.

The selected type is saved with the gateway and shown in the panel. This is the functional difference from v1: v1 creates proxy-enabled gateways, while v2 can create either type.

**فارسی**

هنگام ساخت گیت‌وی، در v2 کاربر پنل می‌تواند یکی از این دو حالت را انتخاب کند:

- **Direct:** رفتار گیت‌وی اصلی `v0.0.0/worker.js` را مستقر می‌کند و بدون پروکسی عمومی به مقصد وصل می‌شود.
- **Non-Direct:** گیت‌وی پروکسی‌دار v1 را با نگهداری پروکسی ترجیحی و جایگزینی پروکسی ناسالم حفظ می‌کند.

نوع انتخاب‌شده همراه گیت‌وی ذخیره و در پنل نمایش داده می‌شود. تفاوت عملکردی v2 با v1 این است که v1 فقط گیت‌وی پروکسی‌دار می‌سازد، اما v2 هر دو نوع را می‌سازد.
